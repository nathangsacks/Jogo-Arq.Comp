
# ArqComp - Minigames

Projeto educativo desenvolvido para a disciplina de
Arquitetura Computacional da São Paulo Tech School (SPTech).

O objetivo do projeto é revisar os conceitos de
Arquitetura Computacional por meio de três minigames
interativos.

## Minigames

### 1. Cruzadinha

Jogo de palavras cruzadas com 16 termos relacionados
à Arquitetura Computacional.

O jogador deve interpretar as pistas e preencher
as palavras diretamente no tabuleiro.

Funcionalidades:

- 16 palavras com cruzamentos;
- Pistas horizontais e verticais;
- Preenchimento das letras no tabuleiro;
- Verificação das respostas;
- Contador de palavras corretas;
- Botão para reiniciar.

### 2. Laboratório Lógico

Minigame sobre portas lógicas e circuitos digitais.

O jogador deve alterar os valores das entradas
para produzir a saída solicitada.

O laboratório possui nove fases, abordando:

- Porta AND;
- Porta OR;
- Porta NOT;
- Porta NAND;
- Porta NOR;
- Porta XOR;
- Circuito AND + OR;
- Circuito OR + NOT;
- Circuito XOR + AND.

O jogo permite testar combinações de entradas,
visualizar as saídas e avançar entre as fases.

### 3. Desafio Binário

Minigame sobre sistemas de numeração.

O jogador precisa converter números decimais
em representações binárias de oito bits.

Cada bit possui um peso posicional:

128, 64, 32, 16, 8, 4, 2 e 1.

Ao ligar um bit, seu peso é acrescentado
ao valor decimal formado.

Funcionalidades:

- 10 fases progressivas;
- Oito bits interativos;
- Conversão de binário para decimal;
- Exibição da soma dos bits ligados;
- Contador de tentativas;
- Verificação da resposta;
- Botão para zerar os bits;
- Botão para reiniciar o desafio.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

O projeto utiliza apenas tecnologias web básicas.

Não são necessários frameworks, bibliotecas externas
ou banco de dados.

## Estrutura dos arquivos

- index.html: estrutura da página e dos minigames;
- style.css: aparência e organização visual;
- script.js: funcionamento dos três minigames;
- README.md: documentação do projeto.

## Como executar

1. Baixe ou clone o repositório.
2. Mantenha os arquivos na mesma pasta.
3. Abra o arquivo index.html no navegador.
4. Selecione o minigame desejado.
5. Comece a jogar.

## Objetivo acadêmico

O projeto foi desenvolvido para auxiliar no estudo
dos fundamentos de Arquitetura Computacional.

Os jogos trabalham identificação de componentes,
portas lógicas, circuitos digitais e representação
binária de números.
