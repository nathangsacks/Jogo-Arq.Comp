# ArqComp — Cruzadinha

Jogo educativo de palavras cruzadas sobre os conteúdos de Arquitetura Computacional da Sprint 3 da SPTech.

## Como jogar

1. Leia as pistas horizontais e verticais.
2. Clique em uma casa ou pista e digite as letras diretamente no tabuleiro.
3. Clique novamente em uma casa de cruzamento para mudar a direção selecionada.
4. Use **Conferir** para visualizar as palavras corretas e incorretas e o contador de acertos.
5. Use **Reiniciar** para limpar todas as respostas.

## Tecnologias

HTML, CSS e JavaScript puros. Abra `index.html` no navegador. Não há dependências nem banco de dados.

## Palavras e pistas

| Palavra | Pista |
|---|---|
| MICROCONTROLADOR | Chip que reúne processamento, memória e interfaces para controlar dispositivos. |
| REGISTRADORES | Áreas muito rápidas dentro do processador que guardam valores temporários. |
| MEMORIADEMASSA | Categoria de armazenamento persistente usada para guardar arquivos e programas. |
| ADDRESSBUS | Conjunto de linhas que indica a posição de memória a ser acessada. |
| DATABUS | Conjunto de linhas que transporta informações entre componentes do computador. |
| DUALCORE | Processador que possui dois núcleos físicos de execução. |
| QUADCORE | Processador que possui quatro núcleos físicos de execução. |
| EEPROM | Tipo não volátil regravável eletricamente, usado para guardar pequenas configurações. |
| FLASH | Tecnologia não volátil utilizada para armazenar o programa do Arduino. |
| CACHE | Armazenamento rápido que reduz o tempo de acesso a informações frequentes. |
| CPU | Componente central que busca, interpreta e executa instruções. |
| ULA | Parte do processador responsável por cálculos e operações lógicas. |
| UC | Parte do processador que coordena a execução das instruções. |
| RAM | Memória volátil usada por programas que estão em execução. |
| ROM | Tipo de memória tradicionalmente associado a dados somente para leitura. |
| DMA | Mecanismo que transfere dados entre periféricos e memória com pouca intervenção do processador. |
